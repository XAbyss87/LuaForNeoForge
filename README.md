## Development Status

**LuaForNeoForge is currently in early development and is not ready for use.**

The project aims to provide a Lua-based modding framework for Minecraft NeoForge written in Kotlin, allowing developers to create mods using Lua instead of Java or Kotlin.

APIs, internal architecture, and implementation details are subject to change without notice. Features may be incomplete, unstable, or undocumented.

Currently, I am only targeting 1.21.1.
